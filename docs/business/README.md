# TMT Business Documentation

## Overview

This folder contains comprehensive business documentation for **TMT (Triage & Monitor for Threats)** - an AI-powered emergency response platform designed for crisis management in conflict zones and disaster scenarios.

> "A startup pitch deck or investor deck should have 10 to 20 slides... It's a narrative. You have to tell a story and get people emotionally invested." - [LivePlan](https://www.liveplan.com/blog/funding/slides-you-need)

## Documentation Standards

### Best Practices Applied

Based on [2026 business documentation best practices](https://thedigitalprojectmanager.com/project-management/document-management-best-practices/):

1. **Single Source of Truth**: All business documentation lives in this folder
2. **Version Control**: Git-tracked for complete history
3. **Classification**: Documents organized by type and purpose
4. **Consistency**: Uniform formatting across all documents
5. **Accessibility**: Markdown format for universal access

### Canvas Frameworks Used

| Canvas | Purpose | Source |
|--------|---------|--------|
| **Business Model Canvas** | Strategic planning & operations | [Strategyzer](https://www.strategyzer.com/library/the-business-model-canvas) |
| **Value Proposition Canvas** | Customer-value fit analysis | [Strategyzer](https://www.strategyzer.com/) |
| **Lean Canvas** | Startup validation & iteration | [Ash Maurya / LeanStack](https://leanstack.com/) |

### Pitch Deck Guidelines

Following [2026 pitch deck best practices](https://www.liveplan.com/blog/funding/slides-you-need):

- **Length**: 10-15 slides maximum
- **Format**: PDF for distribution
- **Focus**: Story over stats
- **Structure**: Problem → Solution → Market → Business Model → Team → Ask
- **Appendix**: Technical details, extra data for follow-up
